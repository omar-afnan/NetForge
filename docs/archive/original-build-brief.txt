==================================================
WHAT IS NETFORGE?
==================================================

NetForge is an interactive networking education platform designed primarily for students learning computer networking.

The platform allows students to:

- Learn networking concepts
- Build and inspect simulated networks
- Interact with routers, switches, PCs, and servers
- Run networking commands
- Observe how packets move through a network
- Break networks intentionally
- Troubleshoot network problems
- Complete networking challenges
- Receive hints and explanations from an AI networking mentor
- Learn from their mistakes instead of simply receiving answers

The central AI component is called:

NETOPS COPILOT

NetOps Copilot is an AI networking mentor that can interact with the student's live simulated network through WebMCP tools.

The AI should not simply be a chatbot.

It should be capable of inspecting the actual network state, running diagnostics, explaining networking concepts, guiding the student through troubleshooting, proposing fixes, and verifying whether a fix worked.

WEBMCP TOOLS
==================================================

Implement tools conceptually equivalent to:

get_network_topology()

Returns:

- Devices
- Links
- Device types
- Basic network structure

get_device_config(device)

Returns:

- Hostname
- Type
- Interfaces
- IP addresses
- Subnet masks
- MAC addresses
- Gateway
- Status

get_interface_status(device, interface)

Returns interface state.

get_routing_table(device)

Returns routing table entries.

get_arp_table(device)

Returns ARP entries.

ping(source, destination)

Runs the actual simulator ping.

trace_route(source, destination)

Runs actual simulated traceroute.

check_connectivity(source, destination)

Performs diagnostic analysis.

get_network_issues()

Returns detected network problems.

propose_configuration_change(device, change)

Creates a proposed fix.

apply_configuration_change(change)

Applies an approved configuration change.

verify_fix(source, destination)

Tests whether connectivity was restored.

FINAL PRODUCT DEFINITION
==================================================

NetForge should ultimately feel like:

"Cisco Packet Tracer meets an interactive networking course meets an AI tutor."

The student should be able to learn a concept, enter a lab, interact with a simulated network, break something, troubleshoot it, ask an AI mentor for guidance, understand the diagnosis, fix the network, and verify the result.

The AI should not simply give answers.

The AI should help the student become better at networking.

The defining technical feature is that WebMCP allows the AI agent to interact with the live network laboratory through real structured tools.

The defining educational feature is:

BUILD → BREAK → TROUBLESHOOT → UNDERSTAND.

Start by auditing the existing repository and report what is already implemented before making major architectural changes.
